03 · Flattening operators

What should happen to overlapping requests?

When an event starts async work, a flattening operator decides whether to cancel, queue, run alongside, or ignore the next event.

In plain language

Pick a rule for what “next” means.

Search might care only about your latest words. A file uploader may need to finish every upload. The operator is the policy that turns incoming actions into async work.

Quick memory aid

Latest · All · In order · First

switchMap latest · mergeMap all · concatMap in order · exhaustMap first while busy.

How to choose

Use switchMap for replaceable work like search. Use mergeMap when every task matters and can run concurrently. Use concatMap when order matters. Use exhaustMap to ignore repeat submits while one is underway.
