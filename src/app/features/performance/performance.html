05 · Performance & cleanup

Keep streams useful, not noisy.

Healthy RxJS code does more than produce the right value. It also stops work when it’s no longer needed and avoids doing more work than the UI can use.

In plain language

Every subscription is work with a lifetime.

When a component disappears, its timers and listeners should usually stop too. For fast events, choose whether to keep the first, last, or most recent value in a time window.

Real-world example

Search without wasted work

Typing can fire many keyboard events. Debouncing waits for a pause before searching, while teardown prevents hidden screens from keeping subscriptions alive.
